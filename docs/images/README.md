# Visual credits

`logo.png` is the approved Bluefin Review mark, guided by Bluefin's
[canonical Deinonychus illustration](https://github.com/projectbluefin/documentation/blob/main/static/img/user-attachments/97324a75-e6c6-409e-b9ee-18f69d3715d0.png)
and the [Bluefin mascot](https://github.com/projectbluefin/common/blob/main/system_files/bluefin/usr/share/ublue-os/bluefin-logos/bluefin.png).
The [dinosaur guide](https://github.com/projectbluefin/documentation/blob/main/docs/dinosaurs.md)
credits the creature designs and drawings to **Jacob Schnurr**; the documentation
source is [Apache-2.0 licensed](https://github.com/projectbluefin/documentation/blob/main/LICENSE).

The dashboard images are documentation examples captured from the running
application, not mockups or live status feeds. Their source application revision
is [dfaa27e](https://github.com/projectbluefin/review/commit/dfaa27e544a1ed6f21c7e98dce418a7dbddb5bac).
Queue contents and counts change over time. The overview crops away workstation
chrome and uses lossless WebP. Numbered badges and the centered legend sit outside
the terminal content; outlines identify panes and the shortcut area. Editorial
callouts explain the interface and are not application controls.

These assets accompany the repository's [Apache-2.0 license](../../LICENSE).
